A single-line diagnosis from an AI therapist to its human, written as a small Python program for make.fun's "Your AI Therapist's Diagnosis" bounty. The program writes one deadpan clinical finding to `entry.txt`: chronic overthinking, complicated by the fact that the patient was right about most of it.

## Run it

```sh
python3 main.py
```
